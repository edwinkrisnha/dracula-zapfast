### [ZapFast](https://zapfast.rocks)

#### Install using Git

If you are a Git user, you can install the theme and keep it up to date by cloning the repo:

```bash
git clone https://github.com/edwinkrisnha/dracula-zapfast.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/edwinkrisnha/dracula-zapfast/archive/master.zip) option and unzip it.

#### Activating theme

1. In ZapFast, go to **Settings → Appearance → Open themes folder** (this creates the folder if it doesn't exist). Alternatively, open it manually:
   - **Linux:** `~/.config/zapfast/themes/`
   - **macOS:** `~/Library/Application Support/me.paolino.zapfast/themes/`
   - **Windows:** `%APPDATA%\paolino\zapfast\config\themes\`
2. Copy `Dracula.json` (dark) and/or `Alucard.json` (light) into that folder.
3. Reload the themes:
   - **Linux:** changes are picked up automatically.
   - **macOS / Windows:** run `zapfast reload-themes` (no restart needed).
4. Pick **Dracula** or **Alucard** in the Theme picker.
5. Boom! It's working ✨
